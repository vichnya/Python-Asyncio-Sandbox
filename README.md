# Python Asyncio Sandbox

Учебный набор задач на Python для изучения асинхронного программирования с использованием `asyncio`.

## Цель

На практике изучить асинхронное выполнение задач, работу с HTTP-запросами, базами данных, веб-скрапингом и взаимодействие клиентской и серверной частей.

## Задания

### `zadanie_1_2.py`

Асинхронная функция для отображения текущего времени в бесконечном цикле.

Изучаются:

* `asyncio`;
* асинхронные функции;
* `asyncio.sleep()`;
* параллельное выполнение задач.

### `zadanie_3_4.py`

Асинхронное взаимодействие с веб-сервером и базой данных.

Используются:

* `aiohttp`;
* `asyncpg`;
* асинхронные запросы;
* работа с PostgreSQL.

### `zadanie_5_6.py`

Асинхронный веб-скрапер.

Задание демонстрирует получение данных с нескольких веб-страниц с использованием асинхронного выполнения.

### `zadanie_7_server.py` и `zadanie_7_client.py`

Простой асинхронный клиент-сервер для обмена текстовыми сообщениями.

Для запуска используются два терминала:

```bash
python zadanie_7_server.py
```

и:

```bash
python zadanie_7_client.py
```
